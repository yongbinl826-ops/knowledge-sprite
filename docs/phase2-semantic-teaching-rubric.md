# 语义教学关联的独立验收判据

事前判据保存在 `evidence/phase2/semantic-teaching-independent-rubric.json`，依据两页实际 TWT 留存正文、FCC pandas 课程声明及四个项目的真实已审批分析。共 21 个真实目标案例：20 个应拒绝、1 个仅允许范围明确的部分关联；另有 3 个来自真实原文的窄目标校准项，明确不是现有项目确认目标，不插入分析、不计入项目覆盖。编写与校验均为零 HTTP、零模型调用，没有改生产或测试源码。

语义模型只解释同一已发现、已核对视频页面或目录中的教学文字。每个 claim 必须绑定候选 ID、当前目标 ID、原字段 evidence ID 和 20–280 字符连续原文；服务端再绑定 point、目标文字、原字段和 provenance 的 SHA。标题、搜索摘要、旁栏、累计 Full Code、脚本、登录受限内容和其他页面的证据不能借用。返回数量最多 12、来源最多 3，复用每单元既有一次 rerank 槽，不增加搜索或详情预算。

| 原文实际讲什么 | 可以关联的范围 | 必须仍未证实的范围 |
| --- | --- | --- |
| TWT 持续主循环直到退出并检查事件 | 独立校准目标中的持续主循环 | 胜利后仍处理事件、R/Esc、重开与退出策略 |
| TWT 屏幕原点与 y 方向 | 独立校准目标中的坐标方向 | 行号乘格子尺寸、格子移动、0..7 边界 |
| TWT 绘制 20×20 网格线 | 独立校准目标中的网格线 | 二维列表、8×8 墙/路/出口、碰撞与配色 |
| FCC 明确讲 pandas 过滤与排序 | 真实“汇总表排序”目标中的通用排序操作，仅部分关联 | 汇总表产生、排序字段/方向、统计口径和复核 |
| FCC 明确讲缺失值、重复值清洗 | 可作为进一步查找的课程线索 | `pd.to_datetime(errors)`、`drop_duplicates(subset, keep)`、`end < start` 与相等时间零分钟规则 |
| 泛称循环、事件、逐帧刷新 | 不足以支持具体 API 或其他工具的目标 | `pygame.event`、`KEYDOWN`、`get_ticks`、JavaScript `setInterval`、Arduino `millis()` 与机械去抖 |

当前绑定的 TWT `video_topic_summary` 没有原 HTML 中的 `clock.tick` 和网格计算代码。即使实际 HTML 含代码，也不能从未入包的代码借引；即使将来有独立合格的 `clock.tick` 证据，限帧仍不能证明真实时间差、胜利后冻结计时或继续处理事件。比较符、数值和明确 API 必须有逐字原文依据，不能由模型补出别名、参数或业务边界。原始按钮边沿同样不能证明机械去抖，必须有稳定时间窗口、稳定采样或有依据的去抖方案。

语义关联固定为 `partial`。原始目标文字和 unknown 行保留，关联片段不能将目标标为 supported，也不能变成整单元教学完整或练习完成。先修说明、否定、将来/TODO、仅列 API 名的片段必须保留其作用范围；不允许裁掉附近限制后引用。

人工验收先核身份/SHA与原文，再判断操作、范围及限制，最后核前端是否保持部分关联和未知项。所有应拒绝案例要求零误接纳；正校准召回单独报告，不能补算真实项目覆盖。真实模型的调用、usage、耗时、原始 claims、服务端接纳/拒绝和独立人工复核需由根任务另存；本文及离线判据不能代替真实模型或生产验收。引用的 replay ID 只属于各自留存快照，实际调用必须经 `build_sources` 重新绑定当前 ID 和哈希。
