## 安全与生产边界

| 范畴 | 当前措施与限制 |
| --- | --- |
| 输入与输出 | 严格类型、长度、引用/循环关系校验；模型完整响应先查密钥和网址再投影；安全诊断不回显被拒正文 |
| 网络与跳转 | 公开域/URL 与重定向安全检查、SSRF 防护、robots/访问拒绝/Retry-After；前端安全协议与外链属性；不绕过平台控制 |
| XSS 与凭据 | JSX 文本渲染、安全封面/链接策略；凭据只在服务器 .env，不进浏览器与报告；不新增凭据 |
| 滥用与成本 | 本地访问、请求体和写请求速率、队列准入、单任务/项目搜索和详情/时限、并发边界；不自动重试结果不确定的模型请求 |
| 韧性与观测 | 缓存、来源冷却、独立平台结果保存、取消与恢复、健康检查和安全阶段诊断；健康 ready 不是第三方实时保证 |
| 持久化 | SQLite 单工作进程、既有迁移、版本隔离；只读一致性备份；不复制测试数据库覆盖用户数据 |
| 公网前置 | 认证反向代理/TLS、真实容量与持续可用性验收、备份恢复演练及部署授权尚需单独完成；本地服务没有多用户认证 |

剩余已知限制：MOOC 上游本轮未召回；四案样本有限；个别名称仍可进一步技术化、部分通用名称可能存在跨技术栈歧义；真实课程的学生阶段与片段教学内容未逐一证明。应称为“本机关键流程验收通过，真实内容有边界的可用版本”，不能据测试数量宣称公开生产已经就绪。

运行、健康检查和回滚规约见 [当前流程说明](current-user-flow.md)。本轮未推送 Git、未外网部署、未购买 API/订阅，也未更改用户历史数据。
