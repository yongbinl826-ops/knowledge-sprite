## freeCodeCamp project course

The actual Learn Pandas & Python for Data Analysis page was fetched from an already observed public candidate. Its formal course declaration, iframe and exact same-ID `youtu.be` watch link establish the published video identity. The old parser rejected the short watch domain. The repair permits only the exact HTTPS short host/path and same video ID; unknown query parameters, fragments, non-443 ports, credentials and lookalike domains remain rejected.

The publisher explicitly introduces projects with “Below are the projects you will build.” The adapter accepts only its named course section, observed difficulty headings and bold project paragraphs. It retains complete teaching sentences plus any negation or prerequisite limitations, within 1800 characters. Author text, conclusions, related links, installation references and code lists are excluded. The actual retained summary is 1634 characters and includes null/duplicate values and grouping operations. It is not a chapter list.

The separately fetched Matplotlib article has full-course watch anchors but no course iframe. Its retained teaching text only establishes a general introduction and installation/reference material. This branch remains unadapted, and neither bar-chart nor Top10 support is claimed.
