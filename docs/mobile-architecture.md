# 无登录手机 APP：数据与接口契约

本文件记录 2026-10-20 的实施边界。原有本地 Web 模式继续使用原路径；`APP_MODE=mobile` 启用面向手机的独立接口和数据边界。手机构建使用 `VITE_DEVICE_MODE=true`，以本机打包的前端资源运行，不依赖把远程网页装进 WebView。

## 数据归属

| 数据 | 存放位置 | 生命周期 |
| --- | --- | --- |
| 项目名称、需求、分析版本、选择、学习进度、推荐结果 | Android 私有 SharedPreferences，经本地 DurableDeviceStore 同步提交确认；浏览器预览使用该浏览器存储 | 本机保留；卸载或清除 APP 数据会丢失 |
| 正在处理的项目、任务、查询、来源证据、临时缓存 | 后端单进程内存 SQLite 和内存对象 | 创建起绝对两小时后拒绝访问；默认每 5 秒检查清理并等待取消收尾；重启失效 |
| 经后端自行校验的公共课程元数据 | 新的独立服务端 SQLite | 可按课程有效期刷新或清理 |
| 全站每日提交与成本额度预留 | 同一个新的公共库中的聚合计数 | UTC 日期聚合；重启保留；不记录设备/项目标识 |
| 模型及检索密钥 | 服务端运行配置 | 不打包进 APP，不返回客户端 |

不提供账号、跨设备同步、用户导入导出备份。APP 禁用 Android 自动备份与设备迁移以符合“仅本机”的约定。内部版本迁移及写入恢复副本服务于可靠保存，不构成用户备份功能。

Android 官方 Preferences 插件的 `set()` 使用异步 `apply()`；回读只能证明其内存值，不能作为“先落盘再 POST”的证据。本地桥接插件在工作队列执行 `commit()`，仅成功后确认写入；前端不回退到内存。双槽及校验和防止半次保存覆盖旧记录。实际断电/强杀后的磁盘耐久性仍须在已安装的手机上验证，浏览器测试不能代替。当前阶段未生成或验证 iOS 工程。

手机模式不打开原有 `DATABASE_PATH`，不自动导入旧项目，也不公开旧 `/api/projects`、`/api/search-jobs` 或任务枚举接口。保留旧库及历史，回滚默认 Web 模式不会要求修改原库。

## 专业知识点与本机确认

显示名为“项目制学习引导小精灵”，应用 ID 与既有存储命名空间不变。知识点只需勾选；点击先后不改变系统内部显示次序。生成名称使用可独立学习的专业概念，项目子任务、用途、目标及先修关系留在解释字段，技术栈单独显示为“检索语境”。“线性表”“栈”是粒度示例，不能无关地加入每个项目。

新分析使用有界重试及结构校验，拒绝功能步骤、章节编号、过宽基础课标题和语法碎片；这不是穷尽所有专业概念的本体库。真实模型对不同领域的语义质量仍需独立验收，合成夹具通过不表示模型生成均正确。

旧历史中隐藏的技术注释不会自动变成检索约束。新服务生成的受校验语境绑定于版本及知识点；设备端在审阅页明确展示语境，再把所选知识点的安全短技术名称作为 `reviewed_topic_technologies` 传给检索。该映射是用户已审阅的检索参数，不是客户端对来源真实性的证明；未知知识点、URL 或指令式值被拒绝。课程匹配仍需课程自身当前教学证据，先修、未来章节和搜索摘要不能补足目标技术。

离线或服务未配置时可仅在本机确认当前选择，保留既有结果为历史版本，明确显示“仅本机确认，未开始课程检索”。重复相同确认不新增版本，联网后必须再次主动点击才检索。不确定是否送达的在线 POST 仍使用原令牌 GET 确认，不当作已知离线自动重发。

## 操作级访问能力

每次用户主动分析或检索前，客户端生成并持久保存 UUID4 `task_id` 和 32 字节加密随机令牌（43 字符无填充 base64url）。该令牌只授权此一次临时操作，不代表账号或永久设备身份。

主动点击分析/检索会将本次项目需求或选中知识点提交后端及其已配置的模型/检索供应商；“仅本机保存”指长期个人记录，不表示分析过程中完全不向服务发送内容。供应商自己的处理与保留政策需在公开发布的隐私说明中列明。

创建、读取、取消均使用 `Authorization: Bearer <token>`；禁止放入 URL、查询参数、日志及可分享链接。后端只保存令牌 SHA-256，恒定时间比较。不同操作不合并个人任务。

```
POST /api/mobile/tasks/{task_id}
GET  /api/mobile/tasks/{task_id}
POST /api/mobile/tasks/{task_id}/cancel
```

创建体按操作种类校验，额外字段被拒绝：

```json
{
  "kind": "analysis | search | direct_search",
  "input": "ProjectInput（analysis/search）",
  "analysis": "AnalysisDocument（search）",
  "request": "SearchRequest（direct_search）",
  "acknowledged_skipped_prerequisites": []
}
```

`search` 可另带 `reviewed_topic_technologies`（最多24个当前知识点名称到安全短技术名称的映射）；`analysis` 不接受此字段。空映射保持旧请求兼容。服务内部批次 `SearchRequest.topic_technologies` 参与缓存/合并身份，避免跨栈误合并；没有技术语境的旧任务保持原身份。

响应包络为 `{task_id, kind, expires_at, status, result}`。分析及项目检索的 `result` 为 `ProjectView`，直接检索为 `SearchResults`。设备端将临时项目/版本标识映射回本机项目。服务器返回的分析快照并不取代本机项目列表。

同 ID、令牌和不可变请求体重放只返回原任务，不重复付费调用。同能力但请求体变化为 409；未知、错误能力、过期访问一致返回 404。取消接口不受“新提交”限额阻塞。任务 ID 的本进程有界墓碑防止过期后复用创建；容量及全站每日提交上限共同限制匿名滥用。

POST 超时或断网后只允许带原能力 GET 确认。服务端重启/过期返回 404 时，手机保留已有版本和结果，等待用户明确选择重试并生成新操作；不会后台自动再次消费模型费用。轮询间隔至少 1.5 秒，无公开 SSE 令牌。

## 共享课程库

```
GET /api/mobile/courses?query=&platform=&offset=&limit=
```

响应 `{items, total, has_more}`，条目只含 `course_id, url, title, platform, thumbnail_url?, author?, resource_type, observed_at, expires_at, access_notice?`。

写入仅由后端自己的页面/目录提取及来源绑定校验触发。搜索摘要、用户标题、用户描述、查询、项目/任务 ID、进度、匹配判断不入公共库。没有匿名创建、修改、删除端点。公共库浏览不声称某课程已经适配当前学习单元；推荐仍经过既有教学匹配流程。登录、付费或地区限制按事实提示，不能被等同为无效链接。

## 运行与成本边界

手机模式使用同一 RAM JobService/ProjectService 队列形成进程级并发边界，按直接连接 IP 进行有界临时速率限制，不信任任意 `X-Forwarded-For`。后台清理必须先取消并等待任务停止，再删个人行、能力和缓存。公共预算以最坏情况下的上游调用额度预留，失败/取消不退款，避免重启或失败重放绕过成本上限。

不得将单进程限流描述成分布式全网防护。公开上线前仍需实际 HTTPS 域名、可信反向代理策略、部署方额度和供应商验收。当前授权不包含外网部署、付费模型调用、凭据创建或系统网络/安全设置修改。

## 平台验收口径

Windows 上可验证 TypeScript/前端构建、原生工程结构、接口与存储的模拟/浏览器流程。只有实际 Gradle 编译、设备/模拟器安装启动后才能声称 APK 可运行；只有 macOS/Xcode 和相应签名验证后才能声称 iOS 可发布。缺少 SDK/JDK、签名或 HTTPS 地址应列为明确前置条件，不能由响应式网页截图替代原生验收。
