## 修复内容

1. 普通采集后按实际结果投影检测视频缺口，避免把只有搜索发现、失效、陈旧或无视频证据的条目计为已补齐。
2. 后台一次 AI 调用返回直接视频地址及精简检索词。直链获取失败或模型没有可靠地址时，通过现有已配置来源进行真实检索，再获取候选页面。AI 输出只作线索；标题、封面、目录和匹配依据均来自实际来源。
3. 原知识点与已确认技术方向优先检索，避免模型用部署等相邻主题替代文件下载；来源瞬时超时可在原任务额度内重试一次。强访问拒绝、验证码、robots、限流等停止条件继续有效。
4. 在现有时间、请求数与详情页预算中预留恢复空间，按知识点轮转检查；同时补查已发现但尚未获取的综合课程目录，避免仅凭标题遗漏具体章节。
5. 修复任务超时后的 `followup_pending` 无休止续跑；过期任务会终止并保留已完成结果。读取结果和重连 SSE 不会触发新的模型调用或搜索。
6. 补齐通用“表单输入控件”和“Word 文档模板填充”的中英文相关参考别名，要求来源自身的技术上下文。保留否定表达、错误技术方向、无关页面和前置知识排除规则；没有按视频 ID 或测试项目名称放宽匹配。
7. B 站匿名公开视频页采用独立的 8 MB 传输/解压上限，页面内状态数据采用 400 万字符上限；保留完整响应、严格 JSON、视频身份与分集归属校验。普通页面、robots、接口和媒体访问范围不扩大。配置 `BILIBILI_PUBLIC_METADATA_MAX_BYTES` 可在 4096 至 16000000 字节内调整；新的缓存版本避免复用旧的 `too_large` 失败。通用“下载按钮”表述只有在来源自身技术上下文吻合时作为相关参考。
8. 前端仅展示普通加载状态、视频封面和标题；不展示 AI 补链、候选地址、后台检索词和诊断流程。
9. 从已验证自身视频页面的前 500 个真实锚点中，提取至多 24 条独立的原生视频链接线索；不扫描 JavaScript 猜地址，不把关联标题混入自身目录。后台每点最多检查 3 条、只走一跳，共用原预算；新目标必须独立获取并提供自身匹配事实。前置补查限时并为后续搜索保留容量。
10. 自身 B 站状态明确 `is_upower_exclusive=true` 的视频作为付费内容排除；零值或缺失不被解释为免费。保留原始证据。真实恢复搜索使用原概念与两个精简模型检索词，最多三轮，访问限制不绕过。
11. 根据真实界面发现的问题，项目视频卡片增加展示门槛：页面必须已获取、`page_verified`、无已知过期/付费标记；相关参考还必须实际引用新鲜的页面或目录证据。仅有搜索摘要的 DLSS 等条目不再混入项目视频推荐区。保留后端原始发现与证据，不把卡片过滤当作补齐成功。
12. 模型输出增加独立的后台诊断：区分未返回知识点、空 URL 数组、空字符串、格式不符、重复和已见地址。统计只包含有界计数与固定标签，不保存模型原文或被拒绝的地址；格式错误保留错误类型，不捏造零条原始输出。此前 `candidate_count=0` 只说明筛选后的直链为零，不能解释为所有模型链接均已抓取并失效。
13. 模型检索词改为互补的中文教学术语与英文核心操作，避免把具体知识点泛化为“入门教程”。真实搜索候选按自身标题、摘要与技术语境排序后再消耗有限的页面名额；排序信息不能替代页面证据。
14. 补齐 `Download Button`、`Downloading Zip Files`、`Email/Contact Form` 等通用英文术语。真实混合课程中按独立分集证据匹配，优先使用 `chapters.N`，避免聚合目录混合技术语境；同时含多个竞争框架的父课不能向未注明框架的分集传递确定技术归属。
15. 前端根据当前推荐实际引用的独立目录证据，选择同一 B 站视频的对应分集。必须有真实来源、父课地址绑定和合法分集地址；不从模型文案或分集序号猜 URL，已明确的分集链接保留。未核验、陈旧、已知付费或其他分集来源均不能提供跳转依据。
16. 模型不可用时仍生成通用双语核心查询，保留已确认技术、版本和复合操作；明确 UI 框架的文件下载可补用 `download button`。最多三轮，不硬编码项目或视频地址，不把查询词作为匹配证据。
17. 恢复阶段在原截止时间内给不同查询轮次留出机会；单点慢搜索不会阻塞其他点的详情获取。已经开始的来源页获取可跨查询轮次继续，整个任务结束或取消时统一清理；不重复消耗同一页面名额，不扩大总预算。
18. 缓存纯相关性计算，完整封印知识点身份/名称/技术、来源资源、证据及其顺序、请求和目录评估。证据、付费状态等变化使缓存失效；缓存有数量/字节上限且返回独立副本。同一只读数据库副本完整结果哈希一致，暖读取从 6.385 秒降至 1.897 秒；这不是线上延迟验收。
19. 主推荐与相关参考指向同一视频时，主卡片可采用该知识点已审核的真实分集地址，保留主推荐标题和状态；主推荐原有明确分集不改。后台缺口判断同步要求相关参考确实引用新鲜的页面或目录证据。
20. 只依据当前自身页面绑定的标题/简介，排除作者明确声明音轨损坏的资源。原始来源证据仍保留，但坏片不参与显示或关闭补链缺口。否定、假设、修复教程、已修复以及主动无配音的视频不被误判。真实第 5 版中的坏音频候选因此不能计为可用视频。
21. 修复“文本分段”和“文本分类”共享“文本分”三个字产生的错误匹配。分段必须有分段/切分或对应英文操作的自身内容依据，不能以分类操作替代。第 5 版原始报告的 7/7 页面匹配，经这项及音频质量复核后实际仅 5/7，修正报告另存、不覆盖原始记录。
22. 识别真实目录中“字符串_split()分割”等带分隔符和明确 API 的名称，以及 `string splitting`、`Splitting a String`。只允许有界标点和明确 `split()` 连接对象与操作，不允许借用远处分集技术、分类、图像分割或否定内容。真实目录回放确认是原先已抓取资源的格式误拒，修复不含视频 ID 或链接白名单。

23. 对恢复搜索已返回的候选，按原 `search_results_per_query` 和全局详情页/时间额度继续逐一检查，消除每轮只取前三条的硬截断。各点轮转，来源真正匹配即停；不增加搜索轮数或总额度。新增反例验证前三条摘要误导、第四条真实目录匹配、命中后不抓第五条，以及预算和跨点公平性。

上述第 12–15 项在暂停恢复后的第六次重启中加载。真实来源诊断发现课程 `BV12T4m1S7a7` 的第 6 集为下载按钮，第 7–9 集为 Streamlit 表单；第 3 集为 Flet 表单，不能借用。第 6、7 集已分别自然播放超过 20 秒，未观察到付费/试看阻断；音频内容质量未审听，记为 unknown。它们没有被人工注入生产数据库；第 8 版已自动检索并显示该课程 P6 下载分集，表单输入另有自身匹配的 P1 视频。

默认 `AI_VIDEO_FALLBACK_ENABLED=true`，`AI_VIDEO_SEARCH_PROVIDER=auto` 复用已配置的 Serper/Tavily 或常规来源，不安装或购买额外服务。每批最多一次模型调用、每点最多三个模型直链；后台检索与获取共用原任务上限。`/api/capabilities` 的 `ai_video_fallback.policy_version=grounded-video-v2` 用于确认运行的是新实现，不等同于覆盖率证明。
