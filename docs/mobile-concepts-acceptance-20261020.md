# 2026-10-20 专业知识点与手机模式验收

本轮交付显示名为“项目制学习引导小精灵”。D 盘项目路径、应用 ID `dev.knowledgeguide.sprite`、Java 命名空间和设备存储键保持兼容。新版本可交付源码、Web 构建及 Android 原生工程；不把浏览器截图和模拟供应商测试称为已发布手机 APP。

## 原失败与修复

1. 稳定轮询反复写公共库：读与清理分离、观察指纹去重；重复读取不再制造 SQLite 写事务，新的自身观察仍可更新。
2. 混合技能及空平台选择低估模型预算：按可能扩展的实际平台及技能路径预留最坏逻辑调用；取消/失败不返还额度。
3. 延迟首个 POST 时过早 GET：提交确认前暂停轮询；不确定提交保留令牌，只查询原任务。
4. Android Preferences 的异步 `apply()` 不能证明先落盘：本地 DurableDeviceStore 在桥接工作队列等待 `commit()` 成功，客户端失败即停止提交。尚未实际编译/执行该 Java 插件。
5. 点击步骤或“Web开发基础”被接受为概念：补结构规则和修复负例，保持其他领域正例。
6. micro:bit、微信小程序及 Web Audio API 只出现在先修或未来课仍被误判：完整技术语境必须与概念处于自身当前教学观察；原 4 红转绿，正确课程样例保留。
7. 离线无法完成知识点确认：增加幂等本机确认，不发 POST、不显示排队检索，也不在重连后自动调用模型。
8. 新语境门控过严地排除父课程标题已明确Pygame/JavaScript、当前章仅写概念的合法资料：恢复既有已验证父课程/当前章节证据链，并重核完整技术名、自身页面ID和当前章标题；错栈、先修、未来及兄弟章节仍不能捐证。新增14项修复控制和8项独立控制，原2个失败样例保留。

原红报告、原始旧测试快照及最终复验记录单独保留。旧测试维护只调整新的生成名称/提示契约；原始 HTTP fixture 字节、供应商安全与预算断言没有被删除以换取通过。

## 可重复本地检查

在隔离副本中运行，避免把实际配置或学生库带入测试：

```powershell
python -X utf8 -B scripts/validate_offline_regression.py --source . --evidence <独立临时证据目录>
cd frontend
node --experimental-transform-types --test tests/*.test.mjs
npm run build
npm run mobile:test
npm run build:mobile:debug -- --api-base http://127.0.0.1:8017
npm run mobile:check
```

后端辅助程序关闭 dotenv 自动读取、清空本进程已知供应商 key 变量并使用 loopback 守卫，保存源码前后 SHA 和退出码；不读取或输出原变量值。全套自身使用合成/临时库与 mock，不能把其通过当作真实供应商已可用。Node 的 transform-types 参数用于现有 TypeScript parameter properties；省略时 strip-only 模式会拒绝两个设备测试模块。

实际 ASGI 联调使用生产路由与生产 Vite 调试构建，不拦截 API；供应商和自身课程页面均为明确合成数据，外部传输被阻断。首个英文合成夹具未通过当前匹配的无结果观察保留；成功流程另提供精确中文自身证据，不通过搜索摘要给它补证。离线浏览器检查只阻断 API、保留本地资产，以模拟已打包手机页面，不是浏览器 Service Worker 离线承诺。

新增两张用户 Library 参考图的元数据可读，但官方 materialization helper 在 Windows 调用 `os.setxattr` 失败，未成功取得可检查像素；没有绕过该步骤或声称已视觉对齐新图。已取得并检查项目内原三屏设计素材，专业粒度按用户明确举出的“线性表、栈”类概念语义实施，不把它们强行加入无关项目。

## 尚不能宣称生产验收通过的条件

- 可用 Java21、Android SDK36 与设备/模拟器缺失。离线 Gradle 在失效 JAVA_HOME 处退出，未生成 APK/AAB、未安装、未验证进程强杀耐久性、原生返回键/安全区/外部浏览器及 OEM 备份禁用执行。
- 未提供真实 HTTPS API 部署域名。release 构建按 `mobile_api_base_required` 退出2；手机127.0.0.1不指向电脑。未创建签名材料、商店账户或扩大权限，iOS 尚无已验证工程。
- 本轮没有新增真实模型/平台请求。真实生成质量、不同学生背景下的需求覆盖、真实推荐相关性、平台登录/收费/地区提示和服务商额度仍需授权环境验收；付费/登录限制不等于链接无效。
- 公开发布仍需可信 HTTPS 入口、实际限额和供应商隐私说明。单进程 RAM 队列与 peer 限流不是分布式防滥用。旧 r16 对新增 legacy 任务字段的读取不兼容，必须按部署文档采用兼容读取器或前进修复，不能直接降级或改写历史。

没有外网部署、Git 推送、真实配置/学生库备份或新凭据创建。代码与资产恢复、公共库恢复、手机本机数据耐久性是独立验收，不相互替代。
