# 教学技能与项目练习合同

本轮修正的是评价与推荐的对象：课程应确实教授分配给它的具体技能，学生再把技能迁移到项目。课程不必使用同一数据集、地图尺寸、引脚、按键或业务常量，也不必独自覆盖整个学习单元。关键方法仍须相符：离散按键不能由持续按键替代，稳定窗口去抖不能由原始边沿替代，真实时间戳倒计时不能由每回调减一替代，加权总量比例不能由各行百分比的平均替代。

## 学生看到的两部分

每个新生成单元含2–4个具体、可迁移的 `learning_skills`，学生可编辑至最多6个，每项最多120字符。同时保留原来的项目子任务、先修、概念、目标、功能要求和验收练习。视频可以分别教授其中不同技能；项目练习保留原输入的全部边界。不会为提高推荐数删掉项目要求，也不会把变量名或参数值拆成独立课程目标。

“先学这些技能”区分两种来源：本课自身简介、目录或已绑定教学笔记的内容依据；本课标题仅声明的主题。标题和搜索摘要不能算正文教学证据，课程身份也不证明教学深度、学生掌握或项目完成。“带回项目练习”呈现原子任务与验收，学生可据此检查迁移结果。

历史版本没有明确技能字段时保持历史语义，不自动改写或生成教学目标。旧的精确项目目标可折叠查看；它的0/N不再充当新技能推荐的总评分。无修改地确认历史计划不会意外创建新版本。

## 来源与匹配

检索直接使用学生审阅的技能，保持公平轮转及原搜索/详情总预算；新技能模式不另做关键词模型扩展。详情优先级可以使用技能词，但查询、搜索标题和网址词都不能证明教学。仅限本次任务已发现的资源，可以把同一真实课程用于不同单元，逐单元重新核对其实际技能与自身来源，不借用另一单元的搜索摘要。

新增的有界模型只判断来源到技能的关系，不生成视频链接、章节或时刻。输入限已知ID、精确技能、学生阶段、技术和选定的本课原文片段；清除链接和可疑凭据/指令片段，保留本地完整原文用于核验。每条结论必须绑定当前课程身份、同URL来源、已知技能、原文连续引文（最多180字符）及整条原始证据的SHA-256。字段、课程、技能、技术、阶段或原文改变均使旧结论失效。明确先修、下节课、未教学及否定不能被标题或截短引文绕过。性质纠错（例如“某API不是某对象”）本身不等于拒绝教学。

普通课程入口不自动成为视频：course/playlist另须独立的本页视频证明与自身目录绑定。已取得真实身份和教学元数据的登录、付费或报名资源可保留访问提示；拿不到的内容保持未知，不声称验证过播放、免费或地区可用。

API以 `teaching_support` 返回来源归属，以 `learning_coverage` 分开汇总内容依据与标题主题。旧 `topic_evidence_status=partial` 用于兼容旧客户端，不表示需要视频复刻整项目；它从不升级成学生掌握或完整项目验收。前端独立复核当前可见卡、技能ID/原文、同源证据、连续引文和全文哈希，平台过滤后重新计算。

## 成本、失败与持久化

同一B站视频的实际分P目录使用精确的BV、原始来源、页号、目录JSON及已观察链接共同绑定；只允许该原生来源给出的正整数 `?p=N`，不拼造章节地址，不允许跨BV、额外参数或片段混入。原有8条观察与6000字符预算内，已验证目录按声明技能的字面标识分配观察槽位；4个候选也优先查看自身确含具体标识的方法材料，保留不同技能的轮转。选择顺序只增加检查机会，不授予教学支持。

实际尝试模型判断前，任务先持久化不进入缓存的未知标记；整批失败、局部绑定失败或取消后，GET不会把缺失结论误作规则回退而复活声明。其他通过自身绑定的独立候选继续内容复核。原始页面、目录、错误与已完成项目版本保留，历史读取仍不写库或触发新模型调用。

`TEACHING_MATCH_MAX_CALLS_PER_JOB` 默认2，只允许0–2，限定初判次数。每批最多5个单元；每单元优先核对至多4个候选，每次初判最多10对、20条支持。每次15秒、输出 `min(LLM_MAX_OUTPUT_TOKENS,3000)`，输入总量最多40000字符。正向声明另经过至多1次内容复核（15秒、最多1500输出token、40条声明、40000输入字符）；最多共3次模型调用。复核专查来源是否支持所归属技能的全部方法，不能把索引访问扩成界面渲染，或把一般事件扩成具体按钮操作。初判关闭时不执行复核。不会自动重试故障。合法空支持表示未知，区别于失败；未复核、复核拒绝或旧未标记的声明不能在读取或缓存回退后复活。

在原任务总时限内，来源阶段为初判与内容复核预留 `min((初判次数+1)×15秒, 总时限/4)`；默认240秒预览中为45秒，不延长总时限。超时取消来源工作后保留资料。模型不可用时，仅在没有旧模型判定时回退到可逐字核对、工具明确、无先修/否定冲突的完整技能主题；已有无效、过期或空模型判定保持未知，不走字面复活。复核失败不缓存成成功的负面结论，支持声明保持未知并提供恢复提示。

有效结论缓存1小时，键含完整绑定指纹。读取结果和历史不调用模型、不重抓页面、不写回证据。历史来源表示当时观察，不能解释为平台实时可用。结论保存在既有SQLite JSON任务/匹配字段与缓存内，没有新数据库表或破坏性迁移；缺省字段的旧版本继续可读。取消和重启沿用中断恢复，不静默重新执行付费模型请求。

对全部新技能模式，最多24单元即最多5批、10次初判与5次声明复核。按默认6000生成输出和1500分析复核输出，完整新分析加搜课的保守输出上限是 `2×6000 + 2×1500 + 5×(2×3000+1500) = 52500 token`，不含供应商输入计费；实际预算和未知来源会减少调用。旧的直接知识点模式仍有原扩展/重排成本，混合请求应逐模式计算。新版本会重新消耗预算，金额取决于现有供应商。增加单次内容复核来自真实首批3卡中发现的2条语义越界；已知三样本控制并不证明泛化，仍须独立验收新项目。

## 验收方式

先冻结独立准则，再审真实生成、真实课程来源与学生适配。课程不必同项目；每条归属必须确实教它声称的技能。保留泛基础、相邻主题、错工具、关键算法不符、先修/未来/展示、伪章节和访问限制等负例。分别报告分析质量、具体技能可学性、标题级线索、未知项、真实用量与离线测试；测试数量不替代内容验收，旧r9c的31单元指标作为历史保留。

## 完整技能与章节线索的新增边界

实际r3复核发现：两次模型判断仍把泛事件标题、数值映射简介或正确使用LED的简介升级成了未声明的具体控制、API或复合技能。新证据门只把目标中明确的方法标识符及可识别的并列/方法限定作为必要条件，原文真实性通过后仍缺成分的声明按合法未知处理；这不是平台无课或链接失效。模型判断、读时重绑和字面回退复用此门，原来源和输入保持不变。旧版本指纹与复核声明失效后不会自动复活。

这是一道保守必要门，不能证明任意语义相似性；尤其同义表达和中英跨语的复合技能可能漏召回。真实来源有证据但判定无效时仍报告未知，不编造模型原输出或失败原因。未知比例和人工修正率必须独立报告，不能仅用拒掉坏卡或通过自动测试宣称达到生产推荐质量。

`related_topic_pointers`仅保留自身已观察章节的原题、原链接和完整证据哈希，每单元最多4条；它是供学生进一步核对的课题定位，完全不增加推荐卡数、技能内容依据或主题支持计数。完整技能和未证成分保留；网页以独立折叠区呈现。章节原题不是观察到的讲课正文，不能补写参数、步骤、硬件引脚或学生掌握。

## 目录适配的工具边界

目录槽位按原声明技能有界轮转、原生URL去重。已有同job、当前point合法复核并完整重绑的空支持结论可以提供pointer-only关联，失败哨兵、旧seal、来源变化及未审来源不能借此进入主要排名或增加覆盖。仅裸DOM/PWM等缩写不能给具体方法提供章节锚。

目录来源自身明确声明软件、芯片、框架或语言等技术主体、与当前技能工具不同，且当前章节没有明确该技能owner时，撤除该可选线索。只看自身已绑定标题/简介/笔记及当前原生章节，不借作者、URL或其他章节；否定、比较、普通英文类别词不当作所教工具。没有新增平台/API/品牌名单。实际FPGA硬件开发线索撤下；Sysblock原文只见建模主题而没有明确工具型别，仍是0覆盖的待核目录，不能解释为已适配游戏方法。

当前原生章节正向明确所需owner时，简介的辅助工具不能误删主题。例如pandas日期章节提到使用faker生成测试数据，仍保留该原目录主题；宽课程标题和别的章节不能捐赠此许可。该规则不升级正文教学支持。跨独立句的父语言/框架关系仍保守处理，可能漏召回，未声称Python与pygame本身冲突；这项局限也不能靠测试通过消除。
