# 当前交付：专业知识点与纯封面选课

此文档以用户 2026-10-19 的最新要求为准：取消昨日新增的教学任务拆解；知识点使用专业名词；点击左侧知识点后，右侧只显示可点击视频封面；B站与 MOOC 并行检索。MOOC 新增免费规则过滤与自身大纲校验，主推荐要求全部所选子项都有大纲依据；B站保留原发现展示。旧阶段文档和旧测试结果是历史记录，不能代替本轮验收。

## 使用流程

检索会优先复用后台仍有效的 MOOC 大纲，并重新核对当前知识点的全部所选子项；不足默认 3 门时继续补搜。共享库及刷新配置只在服务端管理，项目和手动界面都显示普通课程卡片，不显示“共享课程库”等技术标签。课程证据按原抓取时间默认保留 7 天，读取或搜索查询不续期；到期、被撤销或策略变化后不再参与推荐。B站仍使用独立来源和原轮数。

本机已开启查询触发刷新：距同一知识点与当前策略最近一次无来源警告的真实成功 MOOC 查询满 24 小时后，下次实际检索即使已有 3 门课程，也在首轮使用原查询槽最多补 1 次刷新查询，不额外增加搜索预算或槽数。没有用户检索时不运行后台定时任务。5 分钟持久化租约避免相邻任务重复触发；查询缓存、失败和来源警告不更新成功时钟。查询词随成功轮次轮换宽泛课程词与具体知识点词，发现的新课程仍须通过自身完整大纲校验，之后才加入 SSE 结果。

服务端本机配置为 `MOOC_REFRESH_ENABLED=true`、`MOOC_REFRESH_INTERVAL_SECONDS=86400`；分发模板默认关闭刷新。实现见 [刷新状态](../backend/app/mooc_refresh.py)、[查询调度](../backend/app/platform_search.py)和[共享课程库](../backend/app/course_library.py)。当前 Tavily/Serper 配置及历史验证见 [共享课程库与 Serper](shared-course-library-20261019.md)。

1. 输入项目名称、功能要求。学生阶段默认初学者，可在偏好中修改，无需填写额外问卷。
2. 分析结果使用适中粒度的专业名称，例如 pygame 事件处理、矩形碰撞检测、pandas 分组聚合。可修改名称、勾选学习和调整顺序；检索使用确认后的名称。
3. 点击查找视频。在左侧切换知识点；右侧显示搜索候选、匹配与大纲校验、已显示数量的实时进度，封面陆续加入。卡片仍只呈现封面链接，标题保留为链接的无障碍名称，封面加载失败使用图形占位，不伪造视频封面。
4. 取消、重试和恢复操作放在左侧。项目版本和原始输入保留，旧学习字段不强制重新填写，也不自动改写历史名称。

新生成流程最多两次模型请求，第二次仅用于有界校验修复；不再调用额外教学评审，不要求 project_task、learning_skills、practice_check 或 learner_profile。历史扩展字段仍可读取。完整模型返回先经过类型、网址、密钥与图关系校验，再丢弃本轮不需要的扩展内容。

## 平台并行与真实链接

`PARALLEL_PLATFORM_SEARCH=true`，本机 `GLOBAL_CONCURRENCY=2`。当前扩量为 B站每点 3 轮、MOOC 每点 5 轮，每次最多 12 个候选；每批最多 80 次搜索、60 页详情、360 秒，五个知识点且双平台时实际计划 40 次查询。额外轮次使用互补查询，首轮候选保存后立刻开始详情校验，不必等全体首轮结束。项目仍先完成所有批次首轮，再补搜；来源限流会缩减实际请求量。

GET SSE 只传递已有任务的结果变化，浏览器刷新和断线恢复不会重新搜索，也不触发上述课程发现刷新。前端收到快照后陆续显示，通过 MOOC 大纲检查才添加课程；断流自动降级读取已有结果。切换项目或版本会断开旧连接。慢或失败的平台不会抹掉另一个平台已保存的结果；401/403、验证码或 Retry-After 仍停止受限来源，不切换身份绕过。配置与本轮证据见 [扩量与流式显示](streaming-recall-20261019.md)。

链接来自真实检索结果和允许读取的公开页面；不能根据模型生成视频地址或章节。课程需要登录、付费或地区授权属于访问条件，不等于链接失效。本轮不自动验证播放；点击封面跳转平台。名称校验只能排除明确过宽或单行语法标题，不能代替人工评价任意课程相关性。

## 验收证据边界

离线接口/浏览器测试使用明确的模拟响应，证明流程、恢复、隔离、预算和安全边界。公开 HTML 样本重放证明解析器兼容已保存样本。真实模型与真实检索另行记录，失败不会被模拟结果替代。历史阶段的教学覆盖评分已随产品范围取消，不作为当前门槛。最新 MOOC 筛选只核对课程自身的大纲原文及所选知识点，不恢复额外模型评审、任务拆解或学习问卷；目录声明不能证明教学深度或实际播放。

MOOC 标题和摘要仅用于筛选值得读取的公开课程页，先修说明、宣传目录和技术名不符的候选不会证明覆盖。完整覆盖课程进入现有封面区；部分覆盖、目录未见、未读取和入口不支持的候选保留在结果的 `mooc_relevance` 诊断中，不填充主推荐。详情请求在既有预算内轮转，免费来源限流后停止该来源，B站继续执行。实测与限制见 [MOOC 相关性验收](mooc-relevance-20261019.md)。

指定设计素材已取得：`design/imagegen/2026-10-18-three-screens-v2/`，三步结构、留白、暖白/石墨/蓝色延续其视觉方向；右侧按最新要求删去文字。Awwwards、Webby、FWA 是品质参照，没有声称获得奖项。浏览器验证涵盖桌面、平板、手机、键盘与减少动态效果；不能等同完整读屏器或所有浏览器认证。

## 运行与部署边界

本轮更新预览地址为 `http://127.0.0.1:8002`，使用既有预览数据副本；原 `8001` 进程和原数据库保留。常规本地启动需要已有 Python 虚拟环境、前端构建和服务器 `.env`，例如：

```powershell
cd D:\项目制知识引导小精灵
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8001 --workers 1 --no-access-log
```

`/health/live` 检查进程，`/health` 检查工作队列，`/health/ready` 只反映配置与最近观察，不保证第三方此刻可用。SQLite 单进程持久化，按现有迁移逻辑升级；上线前需要单独批准外网部署、认证反向代理、TLS、备份恢复演练和实际容量验收。当前授权只包括本地实现、运行和测试，未推送 Git、未外网部署。

更新前必须重新核对原工程目标文件哈希、Git HEAD/index、进程身份和空闲队列，备份源码/构建/私有配置及一致性数据库。发现并发改动就停止覆盖。回滚只恢复本次备份对应的源码、构建和配置，再以相同单工作进程方式启动；不要用测试数据库覆盖用户数据。数据库恢复须单独核对更新后产生的合法用户数据。
