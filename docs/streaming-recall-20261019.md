## 流式行为

- 直接任务与项目版本都提供 SSE `snapshot` / `complete`。连接只读取已有结果，不创建检索、不调用模型。
- 后端每 350ms 检查 SQLite 更新计数，有变化才重新投影，快照内容相同不重复推送，空闲时发送心跳。
- 页面显示“搜索候选 → 匹配与大纲校验 → 已显示数量”，保留已到达封面。确认失效的视频仍可被正常移除。
- MOOC 未验证候选不先塞入封面区；确认大纲后直接加入。前端不伪造课程或证明。
- 断流回退只读轮询；切换项目、版本、卸载或任务结束关闭连接。旧版本数据不会覆盖新版本。
- `checking` 为正在执行的详情数；`filtered` 和 `unknown` 为 MOOC 知识点与课程配对数，不能与跨平台资源去重后的候选数直接相减。

## 免费 API Key 配置

当前仍是 Tavily keyless；没有开通付费服务。官方说明免密模式适合有限试用；免费账户每月 1000 credits、无需信用卡，Basic Search 每请求 1 credit（[官方额度说明](https://docs.tavily.com/documentation/api-credits)、[免密说明](https://docs.tavily.com/documentation/keyless)，2026-10-19 核对）。免费 Key 也不保证所有课程可检索。

在 Tavily 注册免费账户、复制自己的 Key，仅写入后端根目录 `.env`，然后重启本地服务：

```dotenv
MOOC_SEARCH_PROVIDER=tavily
TAVILY_API_KEY=填写自己的免费账户Key
TAVILY_ALLOW_KEYLESS=false
```

Key 不放入前端、聊天或 Git。保持免费计划，不启用自动付费；应用继续使用 Basic、缓存、独立预算和限流停止规则。配置 Key 后的新实测需要真实返回才能判断 MOOC 数量改善。
