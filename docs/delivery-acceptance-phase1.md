## 验收方法与证据边界

学习内容按“需求覆盖、可形成一个项目子任务、必要先修、无无关项、技术约束一致”逐项精读。代表项目包括 Python 小游戏、数据看板、网站/APP 和 Arduino；beginner 与 intermediate 的八组合均有离线样本。旧真实模型共有七条确定请求，另有本轮真实浏览器分析；Python、看板和 Web 的 intermediate 组合没有真实模型覆盖，Arduino 未执行实体固件。有限语义 guard 无法证明任意模型输出都正确。

视频验收分别记录新网络请求、保存证据回放、按合理粒度重审与人工精读。原复合压力单元失败继续保留。将 pandas 聚合与 Matplotlib 绘图拆为两个正常学习单元，有不同的工具与项目练习边界，不能据此改写原压力测试结果。单资源完整、部分、待核验与集合互补各自报告；“完整”只表示请求主题有来源依据，不代表逐分钟审课或无先修要求。

本机 SearXNG 当前只保留 Bing 一般搜索与 DuckDuckGo Videos；请求超时或搜索索引缺失会影响召回。不得通过降低相关性标准、固定塞入验收 URL、伪造章节或绕过来源限制来补齐数字。真实检索未满足全部代表单元之前，视频核心功能不列为生产通过。

最终冻结后端全量回归：**1697 passed、26 subtests passed，67.85 秒**，有 1 条既有 Starlette/httpx deprecation 提示；见 `evidence/backend-final-frozen.xml`。这组测试没有替代真实接口或教学精读。当前 v2.3 真实模型单次请求 13.110203 秒、2253 completion token、`finish_reason=stop`，七个学习单元经独立静态精读通过。v5 末次调用的 11.270 秒不是当轮总耗时：该轮含一次 JSON 修复，两次模型调用合计 21.805 秒，而且旧主循环说明的语义缺陷被保留为失败。
