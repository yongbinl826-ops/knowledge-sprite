# phase3 r2 独立静态审核

读取实际持久化结果并按事前准则审核，零上游请求、零模型调用、零数据库写入、零源代码修改。详细字段、原文、哈希和不可变快照见同名 JSON。

- **可确认检索**：骑行 CSV v7（7 单元）、迷宫 v7（6 单元）。需求、关键算法、适中粒度、先修顺序与学生背景未发现明确 P1/P2。课程可以用其他项目、数据列名、格子尺寸或常量教授对应技能；不要求同款项目。
- **先修订**：Arduino 反应游戏 v6 第一单元自检要求尚未讲授的按钮电平/串口程序；Streamlit 看板 v3 总方案日期解析写成 `format='YYYY-MM-DD'`，与单元正确的 `%Y-%m-%d` 矛盾。各提供仅一字段的 student_edit proposal，其他内容和输入不变。它们不是首次生成通过。
- **无法评语义通过**：番茄钟 v6 最终 invalid_json；历史显示先有 4 项模型复核问题，但没有保留具体问题或拒绝草稿。Pong v2 两次 quality guard 未过，最终指向 k8 的 unresponsive_game_restart；同样没有草稿，不能断定其实际表述。

另有可复现的检测器 P2 风险：真实已接受迷宫技能“区分暂停玩法逻辑与退出主循环”被 `_stops_whole_game_loop` 误判为停止指令，显式 Esc/关窗退出也在构造测试中被拒绝。坏的“获胜停主循环后 R 重开”仍应拒绝，不能用邻近合法退出句整体豁免。该风险不等于已证明 Pong 实际失败原因。

4 份保存分析共 24 单元，其中 13 单元所在两案可确认，11 单元所在两案各需一处明确修订；不是所有单元均有缺陷。未执行学生项目、硬件或 pandas。日期格式本地演示只使用标准日期格式指令，环境未安装 pandas。实际推荐的来源/教学效用、访问限制和视频身份仍待最终结果独立审核。

累计 run.json 的顶层 prompt 仍是旧 v3；本轮各版本持久化 prompt 为 v3.1。成本与耗时须使用实际 observer 事件，不按累积文件头、失败次数或预算上限推算。
