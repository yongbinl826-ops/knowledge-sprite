## 初始项目与最终运行方式

初始目录为空，没有本地 AGENTS.md、README、现有代码或 Git 仓库；本次按照用户给定的空目录技术栈建立项目。没有清理或覆盖既有业务文件。

- 后端：Python 3.13、FastAPI、Pydantic、HTTPX、Beautiful Soup、SQLite；单 worker。
- 前端：React、TypeScript、Vite；中文单页。生产构建由 FastAPI 同源提供。
- 默认 SearXNG；本次实际部署了官方 GHCR 镜像 `2026.10.11-ad46ebd7d`，digest 固定于 Compose。Docker Hub 初次拉取校验失败的路径未继续使用。
- 默认 `live`，没有演示模式或预置课程回退；未接入 Tavily/LLM Key，未购买任何服务。
- 运行入口：`http://127.0.0.1:8000/`；搜索服务仅绑定 `127.0.0.1:18780`。
- 本机 `.env` 明确选择 `DNS_RESOLVER=cloudflare_doh`，以解决系统 Fake-IP DNS。`.env.example` 仍默认 `system`；未更改操作系统 DNS、代理或安全设置。

启动及故障处理见 [README](../README.md)。所有 Key 仅使用服务端配置；真实本地 SearXNG secret 与 `.env` 已列入忽略规则。

## 已经实现

| 要求 | 实现位置与行为 |
| --- | --- |
| 可替换搜索层 | `providers.py` 的 SearchProvider、SearXNGProvider、TavilyProvider；统一真实候选，保留 candidate_id、查询、时间、来源。 |
| 任意知识点查询 | `queries.py`：原词、教学意图、基础、语言、版本；两个不限站点查询和偏好平台查询；可选模型扩展。没有课程词表。 |
| 异步任务与预算 | `service.py`：持久队列、分阶段逐步保存、逐知识点轮转、搜索重试计预算、详情预算和任务期限、单站点串行。 |
| 数据与证据 | SQLite 分别保存任务、知识点、资源、匹配、证据、查询记录和缓存。去重不丢多对多关系，字段有出处。 |
| 静态采集 | `fetcher.py` 与 `extractor.py`：独立站点策略、robots、逐跳安全检查、有限 HTTP、JSON-LD、OG、标题、语言、可证实目录。 |
| 访问限制 | 识别 401/403/404/410/429、登录页、验证码页、200 错误页、JavaScript 需求；停止受阻路径，不逆向私有接口。 |
| SSRF | 每跳 DNS/公网 IP 检查、固定连接已核验 IP、原域 TLS SNI、禁用隐式代理；浏览器回退关闭。 |
| 规则与模型 | 先过滤/排序；版本冲突、搜索页、广告、先修要求误匹配处理；模型只返回已有 ID/证据与顺序，失败回退规则。 |
| 中文页面 | 多知识点、条件、分组、筛选、真实计数、缓存时间、未知访问条件、证据展开、原平台跳转、错误及中断。 |
| API | 五个要求接口均实现；静态生产页、接口文档、配置能力状态，不返回密钥。 |
| 可重现交付 | pyproject 精确版本、uv.lock、带哈希 requirements.lock.txt、npm lock、Compose、启动脚本、离线与联网脚本。 |

实际并发采取保守串行调度，上限不超过配置的 5，同一站点为 1；没有将初始预算称为性能承诺。默认 180 秒可能先结束任务，已保存的结果仍可访问。

## 当前限制与结论

真实搜索和真实公开页面提取已各自取得成功证据，也验证了一个没有预设过的 CSS 知识点能返回新链接；这些结果不保证以后任意知识点或任何搜索时段成功。当前 SearXNG 部分上游引擎故障，新增 D3 查询全部失败，因此**不宣称全面联网验收通过**。

规则排序是保守的文本启发式，不是语义完备证明。部分结果是文字教程/参考页面，类型如无证据保持 unknown；系统不把所有结果伪称为视频。目录中出现词语也不等于完整讲解，来源页可访问也不等于学生能够观看。

单任务详情预算和串行请求使页面补全可能在期限前未完成；仍展示已发现链接、实际处理计数与限制。旧任务保持原始证据快照，新规则用于新任务。若需要重验网络，使用同一联网脚本输出一个新文件，不覆盖现有失败报告。

依赖来源、许可证与完整清单分别见 [第三方说明](../docs/third-party.md) 与 [依赖清单](dependency-inventory.json)。
