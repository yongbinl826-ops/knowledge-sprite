# MOOC 公开课程 HTML 读取范围复核（2026-10-17）

本复核仅读取官方条款与 robots，未请求课程页，未改生产代码。共 2 / 4 个网络请求：官方协议一次网页工具读取、robots 一次匿名实际 HTTP GET。

## 已核实

- [官方协议](https://www.icourse163.org/topics/mooc_privacy_service/)当前仍显示更新/生效日期 2021-07-16，与同日正常浏览器正文相关条款一致。网页工具没有给出源站 HTTP 状态，该字段保持 unknown。
- 3.1 区分公开课程信息浏览与登录后观看、学习。5.2.7 涉及未经许可的第三方工具/服务接入，但未明确列举匿名公开课程 HTML GET 或爬虫。不能将它缩窄为“仅登录限制”，也不能扩大为“已明确禁止所有公开页面采集”。8.6 的内容再使用限制仍适用，不能据此批量复制课件或媒体。
- [robots.txt](https://www.icourse163.org/robots.txt)本次匿名 GET 真实返回 **HTTP 404**，未重定向。原始响应 169 bytes；SHA256：91fe1bb2ce31dfa39896c9a04ee23274a7e9dd0ad1fc91ec191e8b7307f652f2。这没有建立任何 Disallow 规则，也不等于得到全部用途许可。

## 建议的实现范围

把“第三方聚合许可范围未确认”作为范围说明保留，不能单凭此标签将公开页请求归为平台明确禁止。可在用户授权下采用明确标记的窄范围实现判断：匿名 HTTPS GET 严格匹配的 /course/<机构>-<数字编号> 页面；只读取该次响应自带的公开元信息与课程大纲。

该范围不包含登录、报名、学习、lesson/private API、POST、账号凭据、媒体和 JS 子资源。重定向每一跳重新核对路径与主机，不通过删除身份相关参数来扩大范围。robots、HTTP 拒绝/限速、验证码、登录/付费门槛、DNS 公网校验及原有预算限流仍执行。404 robots 没有禁止规则；401/403/CAPTCHA 等真实拒绝应按原样停止和记录。

页面文字目录应标为“公开课程大纲”。不存在的视频地址、时长、播放进度和播放可用性保持 unknown；保存实时请求时间、源 URL、响应 hash、提取来源。上述是受边界约束的实现判断，不能表述成平台已经授予书面自动聚合许可。

B站保留已核实的 5.6(3)、1.5 明确条款限制，本复核不改变其状态。
