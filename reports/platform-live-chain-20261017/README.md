## 限制依据及判断边界

- **B站**：[官方用户协议](https://www.bilibili.com/blackboard/protocal/licence.html)，更新2025-04-30、生效2025-05-07。5.6(3)要求以自动程序、脚本等获取平台内容/数据前取得明确书面许可；1.5涵盖未注册用户。当前项目没有该许可，因此保留 `site_policy_blocked`。没有通过换接口、换凭证或登录采集规避该路径。
- **MOOC**：[官方用户协议](https://www.icourse163.org/topics/mooc_privacy_service/)，更新及生效日期2021-07-16。3.1允许浏览课程信息；5.2.7限制未经书面许可的第三方工具、服务接入。尚不能确定匿名后台元信息聚合属于何种许可范围，因此保留 `policy_unreviewed`。**这是应用采取的暂停判断，不是已经证明MOOC明确禁止一切公开HTML抓取，也不是网络故障。** 3.1并未单独确认后台聚合器的接入许可。
- robots 与服务条款分别判断：B站 robots 的有限路径规则不能覆盖上述书面许可要求；本次 MOOC robots 的网页工具错误没有源站 HTTP 状态，不能据此推定禁止。详情流程因更早的站点策略停止，未执行 robots 请求。

两站协议均在本轮普通浏览器中实时打开并读取正文；观察时间、版本、原文片段及 SHA256 见 [浏览器条款证据](policy-browser-evidence.json)，截图见 [B站](bilibili-policy.png)、[MOOC](mooc-policy.png)。完整可见正文分别保存在 `bilibili-terms-visible.txt`、`mooc-terms-visible.txt`。页面可见文字不提供 HTTP 响应码，该字段保持 unknown。

## 已修复

1. 空目录且动态补全超时、未完成或依赖受阻时，不再长期缓存为完整成功；最多短缓存300秒，过期失败不再 stale 回用。渲染预算耗尽不缓存。已有页面与目录证据保留。
2. 目录缓存加入平台条款版本；未知平台入口还覆盖重定向/目录后续页可能涉及的平台。条款变更使旧判断失效，但不删除历史证据。
3. API及界面显示具体条款、版本、生效日期和核验方法；日期不再凭空补出08:00。新证据记录具体 `blocked_target_url`，只声明该受限目标未发请求，避免重定向时错误声称整个资源从未请求。
4. 联网审计回调写入失败不改变生产返回/异常，改为标记审计无效；开始事件与最终DNS快照分开。只允许在没有排队/运行任务时 `--resume`，保留原始启动记录与任务。
