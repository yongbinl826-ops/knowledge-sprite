# 前端实现与验证报告

执行日期：2026-10-13（Asia/Shanghai）。最终完整测试为 8 项通过，运行 8.2 秒；构建通过。原始结果见 `e2e-results.json`。

## 已实现

- React + TypeScript + Vite 中文单页；多知识点去重与最多 5 项校验，基础、语言、版本、项目背景、偏好平台。
- POST 提交真实任务，轮询任务和阶段性结果；实际计数，不使用模拟百分比。URL 保留任务 ID，刷新可恢复读取。终态读取保证结果与任务状态一致。
- 按知识点分组，同一资源保留多知识点关系；来源平台筛选、未知元信息、访问条件、证据等级、来源记录、字段出处、目录证据、缓存时间与过期标记。
- 正常无结果、部分失败、全部服务失败、页面受阻、任务中断分别提示。后端不可达和 HTTP 请求失败可重试。
- 所有课程资源均来自后端；客户端没有演示模式、预设资源回退、远程视频播放或 API Key。
- React 转义外部文本；HTTP(S) 外链新窗口附带 `noopener noreferrer`。
- 模块分拆为输入表单、结果面板、资源卡片、能力区、API 与轮询 hook；独立读取并行执行，有卸载取消与有限网络重试。

## 浏览器与运行环境

- URL：`http://127.0.0.1:5173/`；Vite 的 `/api` 和 `/health` 代理至 `http://127.0.0.1:8000`。
- 浏览器路径：会话未列出 Browser 插件及 browser skill。自动测试使用 Playwright 1.64.0 + 已安装 Microsoft Edge Chromium，无头隔离上下文；根代理另用内置浏览器验收实际后端。
- 默认 Chromium Headless Shell v1248 下载遭远端关闭连接，自动重试后仍下载较慢，停止下载并显式改用现有 `msedge` 通道。此失败未当作应用失败或成功掩盖。
- Windows PowerShell 复现：`$env:PLAYWRIGHT_CHANNEL='msedge'; npm run test:e2e`。没有 Edge 的环境先运行 `npx playwright install chromium --only-shell`，再不设该变量执行测试。
- Node.js 24.14.0；锁定依赖见 `frontend/package-lock.json`。直接依赖 React 19.3.0、React DOM 19.3.0、Vite 8.3.4、TypeScript 7.0.2、@vitejs/plugin-react 6.1.2、Playwright 1.64.0。
